# Физика: тепловые явления (8 класс)

Пример для демо: та же система проверяет расчётные задачи по физике. Файлы собирает
`uv run python -m dataset.heat` из `tools/dataset/dataset/heat.py`; `tests/grading/testHeatSamples.py` следит,
что они не разошлись с генератором и что ответы банка верны.

| Файл | Что внутри |
|---|---|
| `zadachi.json` | 14 задач: Q = cmΔt, λm, Lm, qm, тепловой баланс, КПД; ответ — число, единица СИ, допуск 2 % |
| `teplovye-yavleniya-kr.docx` | контрольная из 5 задач банка: нагревание, плавление, лёд → вода, смешивание, КПД |
| `ivanova-olga.docx` | всё верно, ответы в кДж, МДж и % — засчитываются как эквивалентные |
| `smirnov-dmitriy.docx` | t вместо Δt; пропущено нагревание льда до 0 °C; 8 г спирта не переведены в кг |
| `kuznetsova-anna.docx` | арифметика 4200·2·10 = 8400; ответ без единицы; КПД перевёрнут (286 %); округление «≈ 50 °C» в допуске |
| `teplovye-yavleniya-raboty.zip` | все три работы одним архивом |

Сценарий: создать КР, выбрать предмет «Физика», загрузить `teplovye-yavleniya-kr.docx`, затем архив работ.
В режиме фикстур (`GATEWAY_TRANSPORT=fixture`) эталоны берутся из `fixtures/references.json`, ответы модели — из
`fixtures/reviews.json`. С ГигаЧатом (`GATEWAY_TRANSPORT=gigachat`, `REFERENCES_PROVIDER=generating`) эталоны этих
пяти задач всё равно приходят из фикстур; чтобы показать генерацию солвера, добавьте в КР задачу из `zadachi.json`,
которой нет в контрольной (например, «Какое количество теплоты выделится при кристаллизации 400 г свинца…»).

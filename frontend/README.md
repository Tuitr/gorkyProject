# Фронтенд учителя

React 19 + TypeScript + Vite. Своего сервера у фронтенда нет: всё идёт через кабинет (`services/cabinet`, API `/v1`).
Dev-сервер Vite проксирует `/v1` на `CHECKER_CABINET_URL` (по умолчанию `http://127.0.0.1:18080`), поэтому страница и
кабинет живут на одном origin и cookie сессии `__Host-cabinet` работает без CORS.

## Запуск

```
docker compose -f deploy/compose.yaml --profile full up -d --build --wait   # из корня репозитория
cd frontend
npm ci
npm run dev
```

Порт кабинета другой — задайте `CHECKER_CABINET_URL=http://127.0.0.1:<порт>` в `frontend/.env.local`.

## Что идёт через кабинет

- вход и регистрация учителя, классы и ученики (создание и удаление);
- работа: DOCX и требования учителя, новая ревизия при изменении;
- эталонные ответы варианта из реестра решателей (`GET /v1/assignments/{id}/references`);
- работы учеников — фото, DOCX или ZIP с DOCX, привязка к ученикам;
- результат проверки, правки учителя, публикация, отзыв в Markdown и отчёт по классу.

Формирование вариантов и заданий работы над ошибками пока отключено — все ученики пишут один общий вариант.

## Распознавание фото

Для распознавания фото обязательны `OCR_URL`, `OCR_API_KEY` и `OCR_MODEL`. Задайте их в корневом `.env`.
В `OCR_URL` укажите полный HTTPS-адрес, который принимает формат запросов Responses API. В `OCR_MODEL` укажите идентификатор модели. [Пример настроек](../.env.example)
Запустите полный профиль из корня репозитория.

```sh
docker compose --env-file .env -f deploy/compose.yaml --profile full up -d --build --wait
```

В разделе «Сбор работ» загрузите один снимок на работу ученика в JPEG, PNG или WebP (до 20 МБ и 36 Мп).
После привязки к ученику воркер удаляет EXIF и отправляет изображение на `OCR_URL`. Форма загрузки показывает домен из этой настройки.
Каждый снимок читается один раз. Зачёркнутое выделяется в расшифровке, а `[неразборчиво]` отмечает
непрочитанный фрагмент решения. Непрочитанные фрагменты и зачёркивания внутри формул сверяет учитель.
Читаемые шаги передаются агенту проверки в Markdown с LaTeX по номерам заданий. В карточке ученика доступны
исходное фото и его расшифровка.

Открыть отдельную страницу для теста OCR можно командой `uv run python -m grading.ocrPreview` из корня проекта.
Она доступна на `http://127.0.0.1:8765` и использует те же настройки OCR из `.env`.
